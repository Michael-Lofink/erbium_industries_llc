# Cricut Upload Reference

For **Cricut Explore 5**, using its **Scoring Tool** and cutting tool in successive passes. Expanded kit: eight electrovore pawns, three upright quantum stones, and eight reversible vent tokens. All dimensions below apply to the **complete uploaded image or arrangement**.

## 2. Add and align the score overlays

Prepare one pawn sheet at a time. Upload its matching SVG below and set the overlay’s **Operation → Score**. Each overlay is one layer containing four horizontal fold lines per pawn.

| Score overlay | Width | Height |
| --- | ---: | ---: |
| [[Table Materials/Quantum Cave/Pawns/Expanded Kit/Score-Overlays/Electrovore-Pawns-1-4-Score.svg\|Electrovores 1–4 score lines]] | **4.2″** | **3.38″** |
| [[Table Materials/Quantum Cave/Pawns/Expanded Kit/Score-Overlays/Electrovore-Pawns-5-8-Score.svg\|Electrovores 5–8 score lines]] | **4.2″** | **3.38″** |
| [[Table Materials/Quantum Cave/Pawns/Expanded Kit/Score-Overlays/Quantum-Stone-Pawns-Score.svg\|Quantum stone score lines]] | **3.1″** | **2.48″** |

The overlay covers the folds; the artwork also contains glue feet and base labels. Use each file’s own dimensions from its table.

1. Select the PNG, confirm its size from section 1, and set its canvas **Position X = 1″, Y = 1″**, with rotation **0°**.
2. Select the score overlay. Keep proportions locked, enter its width from the table above, and check its height. Set **Position X = 1″, Y = 1.35″**, with rotation **0°**. These coordinates place the first score line 0.35″ below the artwork’s top edge. For artwork already positioned elsewhere, use the same X and add 0.35″ to its Y.
3. Zoom in. Each body should have a line at each glue-foot fold and two lines around the narrow top spine. The lines should sit over the printed dashed guides. The base labels stay clear of scoring.
4. Select the matching PNG and score layer in the Layers panel, then **Attach**. Keep the PNG as **Print Then Cut** and the overlay as **Score**; **Flatten would convert the score lines into printed artwork**. Check the mat preview for the same alignment and save the project.

Each electrovore overlay has **16 lines**; the stone overlay has **12**. Set up and attach each sheet separately. Vents and position markers use their existing Print Then Cut images.

## 3. Print, score, and cut on Explore 5

Choose **Make** and print through Design Space on Letter cardstock so Cricut’s sensor marks appear on each sheet. Use single-sided printing at **100% scale**, with Letter paper and portrait orientation selected. Place the printed sheet on the mat as shown and choose the setting for your cardstock.

Follow Design Space’s prompts to install the **Explore 5 Scoring Tool** and run the scoring pass. **Keep the mat loaded.** When prompted, replace the Scoring Tool with the cutting tool, close the clamp, and press Go to finish cutting. Unload after the job finishes. The vent sheets require the cutting operation only. [Cricut’s Explore 5 scoring instructions](https://help.cricut.com/hc/en-us/articles/38613473602455-Cricut-Explore-5-How-to-use-the-Scoring-Tool)

Start with one pawn sheet and check that its creases follow the printed guides before running the remaining sheets.

The pawn bases finish at one inch across. Each vent backing measures **2″ × 1″**. The optional cores stiffen the upright pawn bodies.

## 5. Assemble

Glue each pawn’s base label to its matching backing. Fold the scored body so the artwork faces outward on both sides, enclosing the optional core if used. Fold the two feet outward and glue them onto the base. Follow the [[Table Materials/Quantum Cave/Pawns/Expanded Kit/Pawn-Assembly.pdf|illustrated assembly guide]] for the folds; make one pawn first to check your stock.

For each vent, glue matching **ACTIVE** and **SPENT** faces onto opposite sides of one backing. Match the identifiers so each token can be flipped during play.

## Optional position markers

Upload [[Table Materials/Quantum Cave/Pawns/Expanded Kit/Print-Then-Cut/Optional-Position-Markers.png|Optional-Position-Markers.png]] as **Flat Graphic / Print Then Cut** and set the complete image to **3.75″ × 0.5″**. This produces six half-inch A/B markers, which can stay as thin paper or cardstock.

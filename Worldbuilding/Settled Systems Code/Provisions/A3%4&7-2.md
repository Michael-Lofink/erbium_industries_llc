# Repossession of integrated components

**Citation:** `A3%4&7-2` · **Status:** example

**Formal title:** Repossession of Biologically or Mechanically Integrated Property

> [!note] Worked example
> This was a drafting example in the old guide. It is not established law.

## What it does

The original guide uses this citation for a proposed rule allowing repossession of leased components integrated into a person’s body.

## Application

This is a worked example, not an established provision. The related example for entry and recovery authority is [[A6%1&8-5]].

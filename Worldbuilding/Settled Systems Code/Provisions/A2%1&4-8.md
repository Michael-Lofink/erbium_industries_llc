# Access to continuity-node data

**Citation:** `A2%1&4-8` · **Status:** provisional

**Formal title:** Continuity Query Access, Disclosure, and Audit

> [!note] Provisional
> This citation is reserved in an existing note. Its standalone law has not been completed.

## What it does

The continuity-node law identifies this as the provision controlling which systems may query nodes and which information they may retrieve.

## Application

Query permissions, disclosure requirements, and audit procedures have not been written in a separate law.

# Where Material Belongs

[[00 - Start Here|Home]] · [[Vault Review|Existing gaps and placeholders]]

| Material | Location |
| --- | --- |
| Session preparation and played sessions | `Campaign/Sessions` |
| Session consequences, GM assessments, continuity | `Campaign/GM Notes` |
| Player characters, personal scenes, card files | `Campaign/Party/<player>` |
| Agreements and shared player documents | `Campaign/Player Handouts` |
| Table feedback and private discussions | `Campaign/Table Management` |
| Locations developed for this campaign | `Campaign/Locations` |
| Setting overview and time conventions | `Worldbuilding/Foundations` |
| Setting history | `Worldbuilding/History` |
| Worlds, regions, and recurring setting locations | `Worldbuilding/Locations` |
| Setting NPCs | `Worldbuilding/People` |
| Credit systems, employment, and society | `Worldbuilding/Society and Economy` |
| Diseases and setting hazards | `Worldbuilding/Hazards and Afflictions` |
| Setting ancestries, archetypes, and creatures | `Worldbuilding/Mechanics` |
| Administrative code and law-writing tools | `Worldbuilding/Settled Systems Code` |
| Rules lookup notes | `Starfinder 2e Rules` |
| Art guidance, GM advice, and starmap data | Corresponding subfolder in `Resources` |
| Images and reference assets | `Resources` |
| Reusable note structures and PES commands | `Templates` |
| Finished PDFs | `PDFExports` |
| Material awaiting classification | `Inbox` |

Keep one working source note per subject and link it from the relevant indexes. A campaign location can remain in `Campaign/Locations` and also appear in the worldbuilding index. Session plans and recorded events stay in their existing session and continuity notes.

Dataview sections discover Markdown notes in their folders automatically. Static PDF, media, and source-file lists can be extended when new files arrive. The “current preparation” link is pinned to Session 2; update it when moving to the next session. Session status tables update from each note’s properties.

PES depends on `Campaign/Sessions`, `Campaign/System`, `Scripts`, and `Templates/PES`. OBS references files under `Campaign/OBS_ASSETS` by absolute path. These paths are retained. Existing images, PDF exports, Discord exports, and PES backups also keep their locations.

Navigation pages are marked `type: navigation` so their Dataview lists can exclude themselves. Existing note titles, YAML properties, rules text, and campaign prose are retained. Full-path ancestry links are updated to the new Mechanics folder.
